# Hannan Labs

Small experiments in software, data and useful things — a lightweight static landing page for [hannanlabs.dev](https://hannanlabs.dev).

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The deployable output is `dist/`.

For Cloudflare Pages, use:

- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`
